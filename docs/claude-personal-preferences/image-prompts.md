## Hướng dẫn sau khi có ảnh

1. **Đặt tên file** theo tên gợi ý (`fig-01-*.png`, `fig-02-*.png`, ...)
2. **Lưu vào thư mục** `docs/claude-personal-preferences/images/`
3. **Thay thế TODO** trong file `.md` bằng cú pháp:
   ```markdown
   ![Mô tả ảnh](./images/fig-XX-ten-anh.png)
   *Caption mô tả ngắn gọn*
   ```
4. **Kích thước khuyến nghị:** Export ảnh ở độ phân giải 1200×675px (16:9) hoặc 1024×1024px (vuông)
5. **Format:** PNG với nền trắng hoặc transparent
