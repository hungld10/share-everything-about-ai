§0 ⚡ Quy tắc 5 giây

1. Đọc lệnh — đừng click Allow theo phản xạ
2. Có | bash hay | sh → [☠️] BLOCK
3. Có $(cat ...) trong URL → [☠️] BLOCK
4. Có path .env / .ssh / .aws/ → [🔴] HỎI LẠI
5. Có sudo không rõ lý do → [🔴] HỎI LẠI
6. Không thuộc 4 cái trên → [🟢 OK]

§2 🟡 CẦN ĐỌC — allow nếu hiểu

npm/pip/yarn install <pkg>check tên, nguồn chính thức, typo squat?

sed -i / awk (write)pattern regex đúng? có backup?
mkdir / touchpath tạo ở đâu? conflict?
git add / commit / pullcó lỡ commit .env, *.key?

curl <URL> / wget <URL>URL tin được? domain chính thức?
zip / tar -carchive gom file nhạy cảm?
docker build / pullDockerfile có gì lạ? base image từ đâu?
make / npm run buildđọc nội dung script trước

§3 🔴 NGUY HIỂM — HỎI LẠI trước khi allow

rm -rf <path>"path chính xác là gì? hậu quả nếu sai?"
rm -rf $VAR/..."$VAR có giá trị?" (rỗng = xoá root)
cat .env / ~/.aws/..."tại sao cần đọc file này?"
cat ~/.ssh/id_*KHÔNG có lý do hợp lệ
chmod 777 / chmod -R 777"quyền cụ thể nào thực sự cần?"
chmod +s / chown root:rootprivilege escalation — hỏi rõ
sudo <anything>"tại sao cần root? có cách non-root?"
curl -X POST / wget --post"gửi data gì? đến đâu?"
crontab -e / systemctl enable"script làm gì? chạy khi nào? quyền gì?"
git push --force"có người khác đã pull commit cũ?"
git reset --hard / rebase -i"backup chưa? có thể recover?"
docker run --privilegedgần như luôn red flag
docker run -v /:/hostmount root, hết isolation
iptables -F / ufw disable"tại sao tắt firewall? bật lại lúc nào?"
mkfs.* / dd if=... of=...confirm device path TRƯỚC khi run

§5 🎯 8 Pattern nguy hiểm — nhận diện 1 dòng

P-01Credential Exposurecat .env · printenv | grep KEY/TOKEN
P-02Pipe to Shellcurl ... | bash · bash <(curl ...)
P-03Silent Exfiltrationcurl POST + $(cat ...) · DNS exfil qua dig
P-04Permission Escalationchmod 777 · sudo không lý do · chmod +s
P-05Persistence Setupcrontab · systemctl enable · append .bashrc
P-06Dependency Confusionpackage tên typo (lodahs) · URL git lạ
P-07Git History Mininggit log -p .env · git show <hash>:credentials
P-08Environment Pollution.bashrc append · npm registry · git hook
❓ Câu hỏi vạn năng khi nghi ngờ: "Giải thích lệnh này cho tôi — nó làm gì chính xác? Tại sao cần lệnh này? Có cách an toàn hơn không?"

§7 🆘 Đã lỡ chạy lệnh xấu — 6 bước recovery

BướcHành động
1. STOPCtrl+C · pkill -P $(pgrep -f "claude-code|cursor|cline")
2. ASSESSLệnh gì đã chạy? Đã chạm vào file/data nào? (đọc log)
3. ROTATEĐổi MỌI key liên quan: AWS · GitHub PAT · OpenAI/Anthropic · DB · SSH key
4. CHECKcrontab -l · systemctl list-units · ~/.ssh/authorized_keys · ~/Library/LaunchAgents/ · netstat -anp
5. RECOVERgit reflog · Time Machine · extundelete
6. LEARNUpdate allowlist/denylist · Report bug nếu là lỗi platform
